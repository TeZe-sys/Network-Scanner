# Network Scanner

A Java-based cybersecurity tool designed to identify reachable devices and scan TCP ports on authorized networks.

## Overview

Network Scanner is a command-line application developed using Java and Maven. It helps users understand basic network discovery and TCP port scanning.

## Features

- IP address reachability checking
- TCP port scanning
- Detection of accessible ports
- Multi-threaded scanning
- Scan result reporting
- TXT and CSV report export

*Features will be implemented progressively.*

## Technologies Used

- Java 25
- Apache Maven
- Java Networking API
- JUnit 4
- Git and GitHub

## How to Run

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project:

```bash
cd network-scanner
```

Build and test:

```bash
mvn clean test
```

## Security Notice

Use this tool only on networks and devices you own or have explicit permission to test.
